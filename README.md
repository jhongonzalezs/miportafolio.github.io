## 📖 Sobre el proyecto

Portafolio web personal construido con tecnologías modernas del ecosistema JavaScript. El objetivo es presentar de manera clara y elegante mi perfil profesional, experiencia, habilidades técnicas y proyectos destacados.

Diseñado con un enfoque **mobile-first**, paleta oscura con acentos dorados, y animaciones suaves que priorizan la legibilidad y la experiencia del usuario.

## ✨ Características

- 🎨 **Diseño moderno** — Estética oscura con acentos dorados y tipografía profesional.
- ⚡ **Rendimiento óptimo** — Vite para un build ultrarrápido y hot module replacement (HMR).
- 📱 **Totalmente responsive** — Adaptado a móvil, tablet y escritorio.
- 🌗 **Componentes reutilizables** — Arquitectura limpia basada en componentes funcionales con React Hooks.
- 📄 **Descarga de CV** — Botón integrado que descarga el PDF actualizado.
- 🔍 **SEO optimizado** — Metatags, Open Graph y Twitter Cards configurados.
- 🎯 **Accesibilidad** — Contraste adecuado, navegación por teclado y estructura semántica.

## 🚀 Instalación local

### Requisitos previos

- **Node.js** ≥ 18
- **npm** ≥ 9

### Pasos

```bash
# 1. Clonar el repositorio
git clone https://github.com/jhongonzalezs/miportafolio.github.io.git
cd miportafolio.github.io

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor de desarrollo
npm run dev
